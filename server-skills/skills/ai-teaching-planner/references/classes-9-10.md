## Calibration for this band
- **Language**: full technical vocabulary, used the way it would be in an intro course — precision, recall, regression, clustering, etc. — always still defined, but no longer over-simplified.
- **Depth**: an end-to-end applied view — students should be able to walk through the AI project cycle for a real problem, not just define terms.
- **Examples**: applied domains relevant to India — agriculture (crop disease detection), healthcare access, accessibility tools, local business use cases, governance/public-service applications.
- **Lesson length**: 40–60 min or double periods for project work.
- **Activities**: guided data exploration on a real (school-safe) dataset, building and evaluating a simple classifier, prompt-engineering exercises with a generative AI tool, structured debates on bias/misinformation case studies.
- **Math**: real but bounded — percentages, ratios, basic probability, reading and computing a confusion matrix, precision/recall by hand on a small example. No calculus, no matrix algebra required (can be mentioned conceptually for neural networks).
- **Coding**: Python-based projects become standard (e.g., using pandas/scikit-learn-level tools or a simplified educational wrapper); no-code/block-based tools remain valid alternatives where devices/Python aren't available.
- **Projects**: multi-session applied projects addressing a real problem in one of the listed domains — full AI project cycle, with a written report and presentation/viva.
- **Assessment**: scenario-based and applied questions, practical coding/no-code tasks, case-study analysis, project rubric assessment, viva questions probing reasoning (not just output).
- **Responsible AI**: case studies, fact-checking exercises, structured ethical-analysis frameworks (who is affected, what could go wrong, how would you check), documentation of AI use in projects.

## Sample analogies / framings that work at this level
- The AI project cycle mirrors the scientific method: define the question, gather evidence (data), form a model, test it, refine it.
- Precision vs. recall: precision is "of the things I flagged, how many were actually right"; recall is "of the things that were actually right, how many did I catch" — use a real scenario like a spam filter or medical screening to ground it.
- A generative AI model is a very sophisticated pattern-completion system trained on huge amounts of text/images — it predicts what's plausible, not what's true.

Avoid: assuming prior programming fluency without checking; unqualified claims about AI "intelligence" or consciousness; skipping the evaluation/limitations step of any project.
